## 📝 Documentation Standards

When contributing to documentation:

1. **Use Markdown** - All docs are in Markdown format
2. **Be Concise** - Clear, direct language
3. **Include Examples** - Code snippets and SQL queries
4. **Stay Current** - Update docs with code changes
5. **Cross-Reference** - Link between related docs
