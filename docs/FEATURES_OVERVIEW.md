# Features Overview

This document provides a concise overview of each feature/view in the Homeschool Hub application, outlining their purpose and key functionalities.

## Dashboard (`/dashboard`)

The main landing page that provides an overview of current activities, upcoming assignments, and recent progress. Displays key metrics, recent lessons, and quick access to frequently used features for efficient homeschool management.

## Calendar (`/calendar`)

A comprehensive lesson planning and scheduling interface with visual calendar views. Users can create, edit, and manage lessons with subject organization, time slots, student assignments, and completion tracking. Supports recurring lessons and drag-and-drop scheduling.

## Assignments (`/assignments`)

Full CRUD (Create, Read, Update, Delete) management system for student assignments. Users can create assignments with due dates, point values, and descriptions, assign them to specific students, track completion status, and grade submitted work with points earned.

## Checklist (`/checklist`)

A daily task management view that displays lessons and assignments for selected dates and students. Features individual completion marking and bulk "mark all complete" functionality for efficient progress tracking and daily workflow management.

## Transcript (`/transcript`)

Academic record management system with full CRUD operations for courses. Users can create courses with grades, credits, terms, and academic years, calculate GPAs, and generate formal academic transcripts for compliance and record-keeping purposes.

## Progress Reports (`/reports`)

Analytics and reporting dashboard that visualizes student progress, completion rates, and academic performance. Provides insights into learning trends, subject performance, and overall homeschool program effectiveness through charts and summary statistics.

## Compliance (`/compliance`)

Hour logging system for educational compliance requirements. Users can log instructional hours by subject and student, track progress toward state requirements, and generate compliance reports for legal homeschool documentation.

## Student Portal (`/student/[studentId]`)

Individual student dashboard featuring personalized checklists of today's lessons and upcoming assignments. Provides a focused, student-friendly interface for independent learning management and progress tracking.

## User Profile (`/profile`)

Personal account management interface for updating user information, timezone settings, and profile preferences. Allows users to customize their experience and maintain accurate account details for the homeschool hub.

## Settings (`/settings`)

Application configuration and administrative tools, including the database seeding functionality. Users can populate their account with sample data (students, courses, assignments, lessons) for testing and initial setup purposes.
